# Bài tập E-learning 01

## Tên bài

Thiết kế giao diện Website Portfolio cá nhân

## Kiến thức sử dụng

- HTML5
- CSS3

## Mô tả

Xây dựng một hệ thống Website Portfolio (Hồ sơ năng lực) cá nhân hoàn chỉnh bằng HTML5 và CSS3 thuần.

Không sử dụng:

- Bootstrap
- Tailwind CSS
- Thư viện JavaScript

Website dùng để:

- Giới thiệu bản thân sinh viên với nhà tuyển dụng.
- Quản lý thông tin dự án của bản thân.

## Tiêu chí chấm điểm

- Kỹ thuật: 70%
- Thẩm mỹ, sáng tạo: 30%
