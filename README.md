# Personal Portfolio Website

Website Portfolio cá nhân được xây dựng bằng HTML5 và CSS3 thuần.

## Mục tiêu

Giới thiệu bản thân và các dự án cá nhân thông qua giao diện Website Portfolio.

## Công nghệ

- HTML5
- CSS3

## Các trang

- Homepage
- Login Page
- Admin Dashboard

## Mục đích

Dự án được thực hiện nhằm đáp ứng yêu cầu của bài tập E-learning 01 môn Lập trình Web và sẽ phát triển thêm trong tương lai.
