# Technical Checklist

## CSS Variables

Định nghĩa trong :root:

- Primary Color
- Secondary Color
- Background Color
- Text Color
- Font Size
- Border Radius

---

## Flexbox

Sử dụng cho:

- Navbar
- Toolbar
- Danh sách dạng dòng hoặc cột đơn giản

---

## CSS Grid

Sử dụng cho:

- Layout tổng thể của trang Admin
- Danh sách dự án ở Homepage

---

## Responsive

Website phải hoạt động trên:

- Desktop (>=1024px)
- Tablet (768px - 1023px)
- Mobile (<768px)
